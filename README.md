# 2048 Game

A browser-based implementation of the classic 2048 puzzle game. Move and merge matching tiles, increase your score, and try to reach the 2048 tile.

## Live Preview

Play the game online: [2048 Game](https://chumachenkoUA.github.io/2048-game/)

## Reference

The project is based on the gameplay of the original [2048 game](https://play2048.co/).

## Technologies Used

- HTML5
- SCSS
- JavaScript
- Parcel
- GitHub Pages

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/chumachenkoUA/2048-game.git
   cd 2048-game
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm start
   ```

## Features

- Classic 4 × 4 game board
- Keyboard controls using the arrow keys
- Tile movement and merging according to the 2048 rules
- Automatic score calculation
- Random generation of new tiles after valid moves
- Win and game-over states
- Start and restart controls
